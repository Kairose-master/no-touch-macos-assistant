# 종합 사무 비서 로드맵

## 1. 현재 구현과 다음 네이티브 검증

실제 한국어 macOS의 전용 샘플에서 Notes headless 작성, EventKit 일정 저장·재조회, Finder 관찰, 승인 후 파일 이동과 커서·전면 앱 불변을 검증했습니다. [실행 절차](native.md)와 [정형 결과](evidence/native-result.json)를 참조하세요. UI 전용 Reminders 날짜 설정과 Finder 메뉴 이동은 검증 성공으로 포함하지 않습니다.

다음은 다른 macOS 버전·언어, 권한 철회, 창 재생성, 사람의 동시 앱 조작, 비동기 iCloud 저장·재실행 후 Notes 지속성, 중간 crash에 대한 reconciliation을 확장 검증합니다. 현재 Notes 성공 근거는 즉시 UI 내용 재조회이며 앱을 종료하거나 iCloud 동기화를 검사하지 않았습니다. 격리 계정이나 macOS VM 설치는 별도 운영 선택이며 자동 설치하지 않습니다.

실제 외부 공유는 정확한 수신자·파일·채널을 승인 카드에 표시하고 전송 영수증과 provider idempotency를 검증할 때 추가합니다. 지금은 로컬 preview만 있습니다.

## 2. 한 Mac의 실용 업무 흐름

회의 메모 → 실행 항목 추출 → 날짜/시간 확인 → 알림 생성 → 관련 파일 링크를 하나의 검토 가능한 계획으로 보여 줍니다. 캘린더·메일·문서 등은 커넥터가 존재하면 먼저 사용하고, UI 자동화가 필요한 마지막 경로만 macOS worker에 맡깁니다. 모델 출력에는 허용된 계획 타입만 받고 실행 코드는 고정합니다.

승인 대기 시간과 실제 작업 시간을 분리해 측정합니다. 작업별 성공률, 결과 불명 비율, ref 복구율, 중복 차단 수를 기록합니다. 실제 사용자 데이터를 모델이나 OTel 외부 exporter로 보내기 전 범위와 보관 정책을 정합니다.

## 3. 팀용 종합 사무 비서

웹 로그인·tenant/session 소유권·승인자 권한을 추가합니다. 모델과 승인자를 분리하고 승인된 정확한 계획에 해시·만료·자원 버전을 연결합니다. 여러 작업자의 desktop queue를 직렬화하고 서로의 세션이 섞이지 않게 합니다.

클라우드 eve 서버에서 발표자의 Mac AX API를 직접 실행할 수 없습니다. 로컬 macOS worker와 인증된 명령 큐가 필요합니다. 클라우드에는 durable 세션·권한·감사를, Mac에는 최소 권한의 실행기를 둡니다. 연결이 끊기거나 결과가 불명확하면 새 실행을 보내지 않고 reconciliation으로 전환합니다.

배포에는 인증된 Workflow world/queue, worker enrollment, 비밀 관리, 감사 권한, 최소 수집, 스키마 버전 마이그레이션과 장애 복구 절차가 필요합니다. Vercel 배포와 VM/권한 설정은 이번 작업에서 수행하지 않았습니다.
